# Páginas OAuth do PEREMPTOR

Este repositório contém apenas as páginas públicas de apresentação e privacidade do aplicativo. Não inclua aqui o banco de dados, backups, chaves de licença, tokens ou segredos OAuth.

O Google exige uma página inicial pública e uma Política de Privacidade pública para colocar o aplicativo OAuth externo em produção. As duas URLs devem usar domínio autorizado e, para verificação, domínio cujo controle possa ser demonstrado no Google Search Console.

Depois da publicação, configure no Google Auth Platform > Branding:

- Página inicial do aplicativo: URL pública de `index.html`.
- Link da Política de Privacidade: URL pública de `privacidade.html`.
- Domínios autorizados: domínio usado pelas duas páginas.

O link de Termos de Serviço é opcional na tela atual e não foi criado, conforme a decisão anterior de não publicar a minuta de termos.
